# Enterprise Order & Inventory Management System

A full-stack enterprise-style **Order & Inventory Management System** built with **Spring Boot, MySQL, React, and Bootstrap**.

The application provides role-based authentication, product and warehouse management, inventory tracking, order processing, stock movement tracking, validation, and automatic inventory updates when orders are created or modified.

---

## 🚀 Features

### Authentication & Security
- JWT-based authentication
- Role-based access control
- `ADMIN` and `USER` roles
- BCrypt password hashing
- Stateless Spring Security configuration
- Protected frontend routes

### Product Management
- Add, view, edit, and delete products
- SKU uniqueness validation
- Product price and reorder-level management
- Product search and status display

### Warehouse Management
- Add, view, edit, and delete warehouses
- Unique warehouse-code validation
- Warehouse location and active-status management

### Inventory Management
- Product-wise and warehouse-wise stock tracking
- Add and update inventory
- Quantity validation
- Automatic stock deduction when orders are created
- Automatic stock restoration when order items/orders are deleted or quantities are reduced
- Transactional inventory updates

### Order Management
- Create single-SKU and multi-SKU orders
- Product + warehouse selection
- Quantity and unit-price validation
- Automatic order-number generation
- Order status workflow:
  - `PENDING`
  - `PROCESSING`
  - `SHIPPED`
  - `DELIVERED`
  - `CANCELLED`
- Status transition validation
- Edit order information while allowed
- Add/edit/delete order items while the order is editable
- Automatic order-total calculation
- Insufficient-stock validation

### Stock Movements
- Tracks stock movements generated by order operations
- Records:
  - Product
  - Warehouse
  - Movement type
  - Quantity
  - Timestamp

### Frontend UI
- React + Vite
- Bootstrap responsive layout
- Bootstrap Icons
- Professional dashboard
- Reusable table component
- Toast notifications
- Confirmation/message modals
- Protected routes
- Responsive CRUD screens

## ⚙️ Backend Setup

### 1. Create the MySQL database

Create:

```sql
CREATE DATABASE order_inventory_db;
```

### 2. Configure database connection

Open:

```text
backend/src/main/resources/application.properties
```

Configure your local MySQL username, password, and database settings.

Do not commit real database passwords or JWT secrets to GitHub.

### 3. Start the backend

From the `backend` directory:

Windows:

```bash
mvnw.cmd spring-boot:run
```

Or, if Maven is installed:

```bash
mvn spring-boot:run
```

Backend:

```text
http://localhost:8080
```

## 🔄 Application Flow

```text
Login
  ↓
JWT Authentication
  ↓
Dashboard
  ├── Products
  ├── Warehouses
  ├── Inventory
  ├── Orders
  │     ├── Create Order
  │     ├── Order Details
  │     ├── Edit Order
  │     └── Order Items
  └── Stock Movements
```

### Order → Inventory Flow

```text
Create Order
     ↓
Validate Product
     ↓
Validate Warehouse
     ↓
Check Available Stock
     ↓
Create Order Item
     ↓
Deduct Inventory
     ↓
Create Stock Movement (OUT)
     ↓
Calculate Order Total
```

Inventory changes are handled transactionally so related database operations can roll back when an operation fails.
